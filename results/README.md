# Result data

- `formal_n9_n6_v3/`: authoritative profiler-off formal result and telemetry.
- `invalid_attempts/`: retained v1/v2 and serial-profile negative evidence.
- `nsys/parallel_steps20_24_analysis.json`: parsed N9/N6 parallel timeline.
- `profile_n9/` and `profile_n6/`: profile-run metadata and hashes.

Large raw reports, SQLite databases, tensors, and complete logs are stored in
the tagged release. No result is deleted from the complete release snapshot;
this Git directory is the review-friendly structured subset.
